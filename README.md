# Calculadora Python

Calculadora básica hecha en Python como parte de mi formación en programación.

## Funcionalidades

- Suma
- Resta
- Multiplicación
- División, con control para evitar dividir entre cero

## Requisitos

- Python 3

## Cómo ejecutar el proyecto

Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
python calculadora.py
```

En algunos equipos con Windows puede ser necesario usar `py calculadora.py`.
